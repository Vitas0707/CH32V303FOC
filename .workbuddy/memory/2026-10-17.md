## 重写 main.c 为完整项目代码

- 原 main.c 为调试态：`Menu_Init`/`VOFA_Init` 被注释，while 内直接 `bldc_olrun()`+`menu3()`，`foc_mode=OPENLOOP`。
- 重写为规范主程序：
  - 完整初始化 `Menu_Init`→`VOFA_Init`→`BLDC_Init`（`Menu_Init` 内部含 `KEY_Init`，不再单独调用）。
  - 上电默认 `foc_mode=IDLE`（安全等待），不擅自设开环。
  - while(1)：`Menu_Run(KEY_GetEvent())` 三屏交互 + 仅 `OPENLOOP` 时 `bldc_olrun()` + `VOFA_Send` 5 通道 + `Delay_Ms(10)`。
  - VOFA 通道数用 `sizeof(arr)/sizeof(arr[0])`，不硬编码（`VOFA_CH_NUM` 宏不在 vofa.h 中）。
- 关键事实记录：
  - `bldc.c::BLDC_Init()` 末尾 ADC1 JEOC 的 NVIC 使能**当前注释**→闭环不跑，仅开环路径可用。
  - `bldc_olrun()` 是绕过 ADC 中断/`FOC_Update` 的独立开环路径（`velocityOpenloop→setPhaseVoltage→BLDC_PWM_SetDuty`）。
  - `menu3()` 是调试用的只画运行屏，完整交互用 `Menu_Run(evt)`。
- 同步更新 README「软件架构」「已知问题」两节，与新 main.c 对齐。

## 删除自写开环代码，启用 ADC 中断走 FOC_Update 内置开环

- 用户要求：不用自写的 `bldc_olrun()` 开环路径，直接用 `FOC_Update()` 里 `FOC_MODE_OPENLOOP` 分支。
- 改动：
  - **bldc.c**：删除 `setPhaseVoltage`/`velocityOpenloop`/`bldc_olrun`/`SysTick_Handler`/`systick_ms`/`openloop_time`/`shaft_angle` 全部自写开环代码；取消 `BLDC_Init()` 末尾 ADC1 JEOC NVIC 使能的注释；移除不再需要的 `#include "key.h"`。
  - **bldc.h**：删除 `bldc_olrun()` 声明，更新 BLDC_Init 注释。
  - **main.c**：删除 while 内 `if(OPENLOOP) bldc_olrun()` 块，主循环只做 Menu_Run + VOFA_Send + Delay_Ms；更新文件头架构注释。
  - **README**：更新软件架构（无 bldc_olrun，FOC 控制环由 ADC 中断自动运行）+ 已知问题（ADC 中断已启用，PID 待整定）。
- 验证：grep 确认 .c/.h 中无 `bldc_olrun`/`systick_ms`/`SysTick_Handler`/`velocityOpenloop`/`setPhaseVoltage` 残留。
- 安全确认：`Delay_Ms`/`Delay_Us` 用 SysTick 轮询模式（CTLR bit5 单次 + 轮询 SR bit0），不依赖 `SysTick_Handler` 中断，删除该 Handler 后启动文件弱定义兜底，无影响。
- 当前架构：ADC1 JEOC 中断(20kHz) 自动调 `FOC_Update`，按 `foc_mode` 分流（IDLE→MOE关 / OPENLOOP→内置开环 / POSITION·SPEED→闭环 / FAULT→过流关）。上电 IDLE 电机不动，菜单选模式后启动。
