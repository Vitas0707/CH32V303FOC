# 2026-10-05

- OLED驱动移植：User/OLED 下的 oled.c/oled.h 从 STM32 HAL 移植到 CH32V303 标准外设库。
  - 硬件：I2C1，PB6=SCL、PB7=SDA（默认引脚，无需重映射），OLED地址 0x78。
  - `OLED_I2C_Init()` 写在 oled.c 前部并在 oled.h 声明，`OLED_Init()` 内部自动调用；时钟 400kHz。
  - 底层 `OLED_I2C_Write()` 带超时保护（0x10000 次计数），防止总线异常卡死（FOC 场景关键）。
  - font.c/font.h 为纯字库数据，未改动。
- 注意：用户确认的引脚是 PB6/PB7；若换硬件需同步修改 GPIO 和重映射。
